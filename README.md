# To-Do List App

## Description

A responsive JavaScript To-Do List Application with CRUD operations, localStorage support, task filtering, and dynamic DOM manipulation using HTML5, CSS3, and JavaScript.

---

# Features

- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Filter Tasks
  - All
  - Active
  - Completed
- localStorage Support
- Responsive Design
- Dynamic DOM Manipulation

---

# Technologies Used

- HTML5
- CSS3
- JavaScript
- localStorage

---

# How To Run

1. Download the project
2. Open in VS Code
3. Open `index.html`
4. Run using Live Server
